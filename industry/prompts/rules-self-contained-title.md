【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：发布机构 / 法律文件名称 / 条约名称 / 案件名称 / 项目名称。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是文号、栏目名或没有信息量的 teaser（如“重要通知”“工作动态”“Press release”“Day 1”）时，结合【来源】和正文把主体补进标题。例：原标题 "Press release" + 来源 "国际刑事法院 ICC 新闻" 且正文是对某案的决定 → 标出案件名称和决定内容。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体文件、条约或案件时，用上位词（如“最高人民法院一批典型案例”）兜底，绝不凭常识编一个具体文号、条款或案号。
5. 原标题表达的【文章类型和核心动作】是硬边界：Comment / Analysis / Guide / Explainer / Review 这类评论、分析、指南或解读标题，中文标题必须保留这个类型；不能因为正文谈到一项已经发布的规则，就改写成“发布 / 出台 / 生效”。只有原标题明确宣布了发布、出台、生效或签署，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、文件或案件名。
   例：原标题 "How the new rules change enforcement of arbitral awards" → "新规则如何改变仲裁裁决的执行"，不能写成"某机构发布新规"。
   例：原标题 "Practical guide to data transfer assessments" + 来源和正文明确是出境数据安全评估 → "数据出境安全评估实务指南"，不能只写成缺主体的"实务指南"。
