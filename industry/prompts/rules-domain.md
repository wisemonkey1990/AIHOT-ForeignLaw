【涉外法治翻译规则 — 本平台内容是涉外法治领域，外文材料（国际组织公告、仲裁与诉讼动态、境外法律评论）译成中文，严格遵守】

1. 法律术语按通行译法，歧义词一律按法律含义翻译：
   - Arbitration = 仲裁；Arbitral tribunal = 仲裁庭；Arbitral award = 仲裁裁决；Seat of arbitration = 仲裁地
   - Recognition and enforcement = 承认与执行；Judgment = 判决；Jurisdiction = 管辖权（视语境为司法管辖或管辖权）
   - Sovereign immunity / State immunity = 国家豁免；Extraterritorial = 域外适用/域外的
   - Sanctions = 制裁；Export controls = 出口管制；Countermeasures = 反制措施；Blocking statute = 阻断法令
   - Treaty = 条约；Convention = 公约；Protocol = 议定书；Ratify / Accede = 批准 / 加入；Enter into force = 生效
   - Due diligence = 尽职调查（国际法语境为“尽职义务”，按语境选择）
   - Binding / Non-binding = 有约束力 / 无约束力；Soft law = 软法
   - Special Rapporteur = 特别报告员；Draft articles = 条款草案；Draft conclusions = 结论草案
   - Investor-State dispute settlement（ISDS）= 投资者与国家间争端解决
   - Mediation = 调解；Conciliation = 调解（国际公约语境译作“调解”并保留英文区分时再注明）
   - Law firm 的 Partner / Counsel / Associate 不译为职务头衔以外的含义

2. 国际组织、机构和条约的名称使用通行中文名；首次出现可附英文缩写，后续保持一致：
   - 联合国（UN）/ 国际法委员会（ILC）/ 联合国国际贸易法委员会（UNCITRAL）/ 国际刑事法院（ICC）/ 国际法院（ICJ）/ 常设仲裁法院（PCA）/ 世界贸易组织（WTO）/ 海牙国际私法会议（HCCH）/ 国际投资争端解决中心（ICSID）/ 国际商会（ICC，与国际刑事法院同缩写时用全称区分）
   - 《联合国海洋法公约》/《承认及执行外国仲裁裁决公约》（纽约公约）/《新加坡调解公约》/《关于豁免国家及其财产的联合国公约》
   - 国内机构：司法部、最高人民法院、最高人民检察院、商务部、外交部、中国国际经济贸易仲裁委员会（贸仲）、中国国际贸易促进委员会（贸促会）、最高人民法院国际商事法庭

3. 以下内容一律保留原文：
   - 案件名称保留英文原文并可附中文译名，如 Chevron v. Ecuador；法律条文编号、条约缩写、文号、日期和金额的数字及单位一字不改。
   - 中国法律文件使用正式全称和文号，不另译；外国法律保留原名并给出通行中文译名，首次出现可双标。
   - 代码 / URL / 数字单位一字不改；金额、比例、期限必须保留原文的阿拉伯数字和单位，不改写成中文数量词。

4. 不确定的译名不要自造：没有通行译法时，保留英文原名，并在首次出现处用括号给出直译。
